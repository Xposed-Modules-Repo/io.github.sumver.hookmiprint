# 小米打印净化+增强模块

本模块适用于小米打印 APP，当前适配版本：**4.1.713 (458)**。

各项功能可在模块设置界面独立开关，修改后需**重启（强制停止）小米打印**生效。

# 功能：

1. **隐藏底部「资源」tab**：下线底部 docker 的「资源」入口
2. **隐藏首页下方内容区**：隐藏首页的在线资源内容区域
3. **为首页添加各类文件快捷打印入口**：在首页直接显示「文档打印 / 照片打印 / 拍摄扫描 / 扫描仪」的二级功能，点击即可直达打印，无需再点顶部「打印」选择类型
4. **我的页面净化**：可分别隐藏「会员中心」「设备共享」「设备耗材」「团队管理」「给小米打印好评」
